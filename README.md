# Mine Game Simulator

## Educational Purpose

This project is an educational simulation designed to demonstrate probability concepts in grid-based games. It is **not** a tool for predicting outcomes in real gambling games, which use certified random number generators that cannot be predicted.

## Features

- Interactive grid-based game with adjustable parameters
- Visual demonstration of probability concepts
- Statistics tracking to understand success rates
- Educational information about how randomness works in games

## How to Use

1. Open `index.html` in your web browser
2. Adjust the grid size and mine density using the controls
3. Click "New Game" to start a new simulation
4. Click on cells to reveal them
5. Try to reveal all safe cells without hitting a mine
6. Observe the statistics panel to understand probability changes

## Learning Objectives

This simulator helps users understand:

- How probability changes as more information is revealed
- Why prediction of truly random events is impossible
- The mathematics behind grid-based probability games
- How to make informed decisions based on probability

## Technical Implementation

The simulator uses:
- HTML5 for structure
- CSS3 for styling
- Vanilla JavaScript for game logic and probability calculations

## Disclaimer

This is purely an educational tool designed to demonstrate mathematical concepts. It is not intended for use in predicting outcomes in real gambling games, which would be:

1. Against terms of service of gambling platforms
2. Potentially illegal in many jurisdictions
3. Mathematically impossible due to true random number generation
